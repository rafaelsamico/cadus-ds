# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-23

### Added

- Initial public release of **Cadus DS** on npm as `@rafaelsamico/cadus-ds`.
- TypeScript type declarations (`.d.ts`) generated on build via `vite-plugin-dts`.
- Library build (ESM) with React/React DOM as peer dependencies.
- Bundled stylesheet exported at `@rafaelsamico/cadus-ds/index.css`.
- Components: Typography plus shadcn/ui set — Alert, Button, Calendar, Card,
  Checkbox, Input, Input OTP, Label, Popover, Progress, Select, Separator,
  Skeleton, Sonner, Tabs, Textarea, Tooltip.
- `cn()` utility from `lib/utils`.
- Design tokens: four OKLCH color palettes (Mata Atlântica, Barro Nordestino,
  Areia Sertaneja, Urucum Amazônico) and three self-hosted typefaces.
